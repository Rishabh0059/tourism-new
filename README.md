🌍 Tourism Explorer
A simple React-based tourism website where users can explore different tourist destinations and learn about their unique attractions.

🚀 Features
✅ Browse and explore various tourist destinations  
✅ Learn about the special things in each place  
✅ Responsive and user-friendly UI  

🏗️ Tech Stack
- Frontend: React.js, CSS  
- State Management: useState, useEffect (React Hooks)

  🛠️ Installation & Setup-
  1️⃣ Clone the Repository
    - git clone https://github.com/Rishabh0059/tourism-new.git
    - cd tourism-new
      
  2️⃣ Install Dependencies
    - npm install
      
  3️⃣ Start the Application
    - npm start

  Live Website: http://localhost:3000
